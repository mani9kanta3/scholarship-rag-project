# pydantic is pinned to exactly this, and it is the only version that
# works. Hugging Face installs gradio with its mcp extra on top of this
# file, and that caps pydantic at <=2.12.5, while google-genai in this
# same file needs >=2.12.5. Two constraints meeting at one point.
#
# Nothing here uses a pydantic feature newer than 2.9, so this costs
# nothing. It is worth a comment because the next person to bump it will
# get a resolver error that names eight packages and not the reason.

# Embeddings and the reranker. Both are inference only and neither needs
# a GPU: this project never calls one.
#
# The version is pinned to 2.11.0 because of where it is deployed, not
# because of what it needs. Hugging Face now charges for the plain CPU
# runtime, so the Space runs on their ZeroGPU hardware, and that only
# accepts torch 2.8.0, 2.9.1, 2.10.0 or 2.11.0. Anything newer is
# refused before the Space will even start.
#
# I also dropped the +cpu build tag. It made the install smaller, but it
# is a local version segment and ZeroGPU matches the version exactly, so
# it was the difference between building and not building. The floors
# that actually matter are torch>=2.2 for sentence-transformers and
# torch>=2.5 for transformers, and 2.11.0 clears both.
torch==2.11.0
sentence-transformers==6.0.0
transformers==5.15.1

# Only used by space_app.py, the entry point for the Hugging Face Space.

# Gradio one, so the API is served from inside a Gradio app. Nothing in
# the project itself imports this.
gradio==6.26.0
