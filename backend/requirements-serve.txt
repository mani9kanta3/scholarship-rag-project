# What the deployed API needs, and nothing else.
#
#     pip install -r requirements-serve.txt
#
# requirements.txt is the development set. It carries PyTorch, the
# cross-encoder, LangChain and the evaluation tooling, and it comes to
# about 700 MB in memory once both models are loaded. The free tier I
# could actually get gives 512 MB, so serving from that file was never
# going to work.
#
# This file drops everything that is only needed offline:
#
#   torch, sentence-transformers, transformers
#       Replaced by fastembed, which runs the same bge-small weights
#       through ONNX. A document embedded either way comes out at cosine
#       0.999999, so the vectors already in Postgres stay valid and
#       nothing is re-embedded. This is the single biggest saving.
#
#   the cross-encoder reranker
#       Needs torch, so it cannot come. Set RERANKER_ENABLED=false.
#       A real loss, and the evaluation measured its effect twice and
#       got opposite answers, so on that eval set it sits inside the
#       noise. Shipping without it beats not shipping.
#
#   langchain, pypdf, beautifulsoup4
#       Only used by ingestion, which runs on my laptop.
#
#   google-genai
#       The alternate model provider. llm.py imports it lazily, so the
#       service runs fine without it as long as LLM_PROVIDER is groq.
#
#   pytest
#       Tests do not run in production.
